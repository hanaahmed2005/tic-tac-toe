# Tic Tac Toe Game

A simple and interactive two-player Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

- Two-player gameplay
- 3×3 game board
- X and O players
- Detects winning combinations
- Detects draw games
- Displays the current player's turn
- Win and draw result messages
- Reset and Play Again functionality
- Responsive design for mobile and desktop
- Pixel-style gaming interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Play

1. Player X starts the game.
2. Click on an empty square to place your mark.
3. Players take turns between X and O.
4. The first player to get three marks in a row wins.
5. If all squares are filled without a winner, the game ends in a draw.
6. Use the Reset Game button to start a new game.
